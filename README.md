# 🥔 PATATES FELSEFESİ ÜRETECİ 🥔

> "Patatesi anlamadan hayatı anlayamazsın."  
> — Bilinmeyen bir patates bilgesi, M.Ö. 4000

## Bu Proje Nedir?

Bu repository, insanlığın en büyük eksikliğini gidermek için doğmuştur: **Patates temelli felsefi derinliğin yokluğu.**

Yıllarca filozoflar varlık, yokluk, özgür irade ve anlam üzerine kafa yordular. Hiçbiri aklına patatesi getirmedi. Biz getirdik.

Bu araç, rastgele ama **kesinlikle bilimsel** yöntemlerle evrenin en derin patates felsefelerini üretir. Her çalıştırıldığında size hayatınızı değiştirebilecek (veya değiştirmeyebilecek) bir söz verir.

## Neden Bu Kadar Önemli?

- Patates, toprağın altında sessizce düşünür. Biz yüzeyde gevezelik ederiz.
- Modern dünya hızla akıyor. Patates yavaştır. Bilgelik yavaştır.
- Bir patatese bakıp kendinizi sorgulamazsanız, gerçekten yaşadığınız söylenebilir mi?

## Kurulum

```bash
git clone https://github.com/Tentivory/patates-felsefesi-ureteci.git
cd patates-felsefesi-ureteci
python3 patates_felsefesi.py
```

Başka hiçbir bağımlılık yoktur. Çünkü felsefe bağımlılık kabul etmez.

## Kullanım

Sadece çalıştırın. Patates ruhu sizi bulacaktır.

```bash
python3 patates_felsefesi.py
```

Çıktı örneği:

```
Patates ruhu çağrılıyor...
Toprak katmanları açılıyor...
Derinliklerden felsefe yükseliyor...

============================================================
  PATATES FELSEFESİ v1.0 - EVRENİN GERÇEK CEVABI
============================================================

  >>> Patates hiçbir şey sormaz. Bu yüzden her şeyi bilir.

============================================================
Bu sözü bir yere not et. Hayatın değişebilir.
veya değişmez. Patates karar verir.
============================================================
```
